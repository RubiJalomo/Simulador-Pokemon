Simulador de Entrenamiento Pokémon

Nombre: Angeles Rubi Ibarra Jalomo
Numero De Control:25151487

Descripción

Este proyecto consiste en desarrollar un simulador de entrenamiento Pokémon utilizando el lenguaje de programación Python.

El programa permite simular actividades de entrenamiento Pokémon y aplicar conceptos básicos de programación orientada a objetos.

Objetivo

Practicar los fundamentos de programación mediante la creación de un simulador Pokémon, organizando el código en archivos separados.

Tecnologías utilizadas

- Python
- Visual Studio Code

Archivos del proyecto

- pokemon.py: Contiene la clase y la lógica relacionada con los Pokémon.
- main.py: Contiene el programa principal para ejecutar el simulador.
